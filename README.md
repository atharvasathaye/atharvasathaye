## Selected Projects

### [Banking Competitive Benchmark](https://github.com/atharvasathaye/banking-benchmark)
Competitive analysis dashboard benchmarking Truist digital banking against peer institutions using 598K CFPB consumer complaints and 2M app store ratings. Features a dynamic RICE framework backlog prioritization.
**Technologies:** JavaScript, Node.js, REST APIs

### [Supply Chain Pressure Analysis](https://github.com/atharvasathaye/Supply-chain)
Quantitative analysis of the relationship between global supply chain pressure (NY Fed GSCPI) and US consumer inflation (FRED CPI). Features a Streamlit dashboard with dual-axis visualizations and Pearson correlation metrics.
**Technologies:** Python, Streamlit, Plotly, Power BI

### [VeriStream AI](https://github.com/atharvasathaye/Cozad)
Video verification platform for deepfake detection. Implements a FastAPI backend with HuggingFace models, multi-signal frame analysis, and a Streamlit dashboard for risk report visualization.
**Technologies:** Python, FastAPI, PyTorch, HuggingFace, OpenCV

### [Career Insights Dashboard](https://github.com/atharvasathaye/Student-Career-dashboard)
Star schema data warehouse for tracking UIUC graduate employment outcomes. Includes a SQL ETL pipeline feeding interactive Tableau dashboards.
**Technologies:** SQL, Tableau
