## Featured Projects

### [VeriStream AI](https://github.com/atharvasathaye/Cozad)
Video verification platform for deepfake detection. Implements a FastAPI backend with HuggingFace models, multi-signal frame analysis, quality gating, and a Streamlit dashboard for risk report visualization.

**Technologies**: Python, FastAPI, PyTorch, HuggingFace, OpenCV

### [Supply Chain Pressure Analysis](https://github.com/atharvasathaye/Supply-chain)
Quantitative analysis of the relationship between global supply chain pressure (NY Fed GSCPI) and US consumer inflation (FRED CPI). Provides a Streamlit dashboard with dual-axis visualizations, Pearson correlation metrics, and Power BI reports.

**Technologies**: Python, Streamlit, Plotly, Power BI

### [Formula 1 Predictions](https://github.com/atharvasathaye/formula-1)
Race result prediction models built on historical F1 data from Ergast API and FastF1 telemetry. Feature engineering pipeline incorporates driver performance metrics, qualifying gaps, and circuit-specific parameters.

**Technologies**: Python, scikit-learn, FastF1, Streamlit

### [Career Insights Dashboard](https://github.com/atharvasathaye/Student-Career-dashboard)
Star schema data warehouse for tracking UIUC graduate employment outcomes. SQL ETL pipeline feeding interactive Tableau dashboards.

**Technologies**: SQL, Tableau, Star Schema Architecture

### [311 Service Requests: Differential Privacy](https://github.com/atharvasathaye/HCD_Differential_Privacy)
Implementation of differential privacy on Chicago 311 service request data. Evaluates privacy-utility tradeoffs across varying epsilon parameters while maintaining spatial distribution accuracy.

**Technologies**: Python, pandas, NumPy, Plotly

### [Healthcare Billing Assistant](https://github.com/atharvasathaye/ABR_Healthcare_Client)
Bilingual AI billing assistant with retrieval-augmented generation over insurance policy documentation. Features a FastAPI backend with OpenAI API integration, Azure deployment, and PII safety guardrails.

**Technologies**: Python, FastAPI, OpenAI API, Azure
